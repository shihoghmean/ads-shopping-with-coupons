documents/ 目录说明与浏览顺序（提交包顶层为 documents/ 与 code/）
================================================================

1. wc_2026G##_P5.pdf    项目完整报告（PR 互评匿名版）。
                        文件名中 ## 为组号占位符，PR 互评阶段按匿名规则不填写
                        真实组号与成员姓名。内容依次为封面页、第 1--4 章正文、
                        参考文献、匿名分工表、独立声明与留空签名栏。

2. results/             第 3、4 章全部实测的原始数据与图表：
   scale.csv              实验族 A：规模扩展（N 从 1000 到 100000，D=10^6）
   k_sweep.csv            实验族 B：固定 N=100000、购买量 K 从 ~100 到 10^6 的梯度反转
   dist.csv               实验族 C：五种典型分布（低价、高价、全相等、阶梯离散、断层）
   huge_budget.csv        实验族 D：突破题面限制的超大预算拓展（D 从 10^6 到 10^14）
   figures/
     fig1_scale.png         总耗时与剔除排序后的核心求解耗时随规模变化
     fig2_k_sweep.png       购买件数 K 梯度下的性能反转与排序/求解占比拆解
     fig3_huge_budget.png   超大预算拓展下堆算法与值域二分的量级分化

说明：
- results/ 中的全部耗时均在同一台机器、GCC -O2、同一批实验内测得，
  仅适合批内横向与纵向对比；换机器或换优化级别后绝对毫秒数不可直接比较。
- 基准输入数据文件较大，不随提交包上传；在完整仓库内执行
  python code/tools/gen_cases.py（固定种子 20261123）即可逐字节复现全部输入。
